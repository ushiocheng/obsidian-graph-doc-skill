# Overview

This repo holds one agent skill. Given a codebase, the skill writes a `docs/` folder that is also an Obsidian vault: one short note per unit, flat YAML frontmatter, and typed links such as `depends_on` and `part_of`. Humans browse it in Obsidian; agents read the index and the few notes for the area they are changing.

There is no build step and no runtime. The repo is Markdown plus one Python script.

## Run and test

- Check a vault: `python3 skills/obsidian-graph-doc/scripts/validate.py docs`
- There is no test suite yet.
